Assistants keep working over MCP while Sequill is closed, or after it closes mid-conversation: `sequill mcp` runs the calls itself on the same data folder, with the same switches and history, and the app shows the changes when it opens. Assistants that Windows runs in an app package (Claude Desktop from the Microsoft Store) still need Sequill open, because Windows gives them a private copy of the data folder.
