Sequill 1.0.0, the first desktop release: a Tauri app on a native SQLite engine written in Rust, with installers for Windows, macOS (Apple Silicon and Intel) and Linux. Databases are real files on your computer and everything works offline. It keeps the table grid, inline editing, SQL console, schema editor and visualizer, and CSV/JSON import and export, and adds a built-in MCP server so AI assistants can read, show and (when allowed) change the same databases.
